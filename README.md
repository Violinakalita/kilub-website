# kiluB — Free Website

A static, responsive kiluB company website built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Publish for free with GitHub Pages
1. Create a GitHub account at https://github.com/
2. Create a new **public** repository.
3. Upload `index.html`, `style.css`, `script.js`, and `favicon.svg`.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then save.
7. GitHub will give you a free `github.io` website address.

## Before launch
- Replace `hello@kilub.com` in `index.html` with your real business email.
- If you later buy `kilub.com`, connect the custom domain through GitHub Pages.
- Do not publish private information such as your home address, phone number, school details or other personal documents.

## Structure
- `index.html` — all website content
- `style.css` — visual design and responsive layout
- `script.js` — mobile menu and footer year
- `favicon.svg` — kiluB browser icon
